### 1.1 M2 一句话目标

在 M1「加密货币单市场告警闭环」基础上，扩展到 **A股/美股/港股自选监控**，并建成 **「信号 → 模拟下单 → 成交 → 持仓 → 盈亏 → 复盘」模拟盘闭环**；规则支持插件化扩展；输出历史数据回测可行性评估。

### 1.2 变更摘要（相对 M1）

| 领域 | M1 已交付 | M2 变更 |
|---|---|---|
| 行情源 | 币安 WS 单适配器 | 新增 A股轮询适配器（东财 push2 主 / 新浪 hq 备）与腾讯轮询适配器（美港股，延迟数据）；QuantApp 支持多适配器并行 |
| 规则链 | 4 条内置规则，币种 1min K 线驱动 | 跨市场复用同一 Rule 链（A股/美港股由 ~3s 轮询快照聚合 1min Candle）；规则支持配置化插件扩展 |
| 看板 | 状态栏 / 行情表 / 告警日志 / 规则面板 | 多适配器状态、市场列、延迟标注、模拟盘账户区、待确认队列；新增 y/n/m 按键 |
| 交易 | 无（仅告警） | 模拟盘引擎：虚拟账户 + 费率/滑点模型 + 双模式（auto / manual） |
| 存储 | alerts / candles 两表 | 新增 signals / orders / fills / positions 四表 |
| CLI | 看板单命令 | 新增 `review` 复盘子命令（按标的/规则/时间查询回放） |

### 5.2 P1-1 A股适配器（M2-P0）

| 项 | 内容 |
|---|---|
| 数据源 | 东方财富 push2（主）+ 新浪 hq.sinajs.cn（备），约 3s 轮询自选清单（配置维护，不做全市场扫描） |
| 产出 | 统一 Candle 模型：轮询快照按自然分钟聚合，分钟收盘 `is_closed=True` 进入规则链 |
| 重试 | 指数退避（1s→30s 封顶，成功重置）；主源连续失败 3 次（可配）切备用源，恢复后切回（沙箱代理瞬断实测可恢复） |
| 预热 | M2-P1：启动时从东财拉最近 300 根 1min K 线灌指标窗口；失败则冷启动，状态栏提示「预热中」 |

| 验收标准 |
|---|
| ① 24h 连续轮询无崩溃；单次网络瞬断 60s 内自动恢复（退避重试） |
| ② 主备源自动切换有测试覆盖（mock 双源响应） |
| ③ 行情字段完整：最新价、成交量、时间戳（取数据源时间，非本地接收时间） |
| ④ 外部 IO 全部 mock / 录制回放，无测试依赖真实网络 |

### 5.3 P1-2 美股/港股适配器（M2-P0）

| 项 | 内容 |
|---|---|

| 验收标准 |
|---|
| ① 延迟标注三处 100% 可见（状态栏 / 行情表 / 告警） |
| ② 字段完整（价、量、时间）；退避重试机制同 P1-1 |

### 5.4 P1-3 模拟盘引擎（M2-P0）

| 项 | 内容 |
|---|---|
| 虚拟账户 | 默认每市场 100,000 计价货币（USDT/CNY/USD/HKD），可配置；现金与持仓隔离核算，重启可恢复 |
| 成交模拟（诚实） | 市价单成交价 = 最新价 ± 滑点（默认 5 bps，全局可配、可按市场覆盖，滑点方向不利于成交方） |
| 费率模型（默认值均可配，按主流费率设定，用户可校准） | 加密货币 taker 0.1%；A股佣金 0.025%（双边）+ 卖出印花税 0.1% + 过户费 0.001%；美股佣金 0；港股佣金 0.03% + 印花税 0.1%（双边） |
| 信号方向语义 | 规则产出方向：`long` = 开仓买入意向 / `close` = 平仓意向。默认映射：金叉·RSI超卖·价格上涨·量突增 → long；死叉·RSI超买·价格下跌 → close。**仅多头方向，不做空** |
| 下单规模 | 每笔 long 使用该账户可用现金的 `position_pct`（默认 10%）；A股买入按 100 股向下取整；现金不足 → 订单拒绝并记录原因 |
| 仓位约束 | 同一标的同时仅一个模拟仓位（默认，可配）；持仓期间同标的 long 信号忽略（记录 ignored）；close 信号无持仓时忽略（记录 no_position） |
| 双模式 | ① `auto`：信号 → 自动下单；② `manual`：仅告警，`y` 确认 / `n` 忽略（FIFO 队首，超时 300s 失效）。模式配置切换为 M2-P0；运行时 `m` 键切换为 M2-P1 |
| 盈亏 | 已实现盈亏（平仓时：卖出成交额 − 买入成本 − 双边费用）+ 浮动盈亏（持仓市值 − 买入成本） |

| 验收标准 |
|---|
| ① 一笔完整交易（信号→订单→成交→持仓→平仓→已实现盈亏）可串联回放（与 P1-4 联动） |
| ② 费用/滑点计算与手工核算逐分对齐（单元测试：给定价格/数量/费率对照，浮点近似容差 1e-6 相对） |
| ③ 双模式均有测试覆盖；manual 模式 y/n/超时路径全覆盖 |
| ④ 边界拒绝全部落库且有原因：资金不足、无持仓平仓、重复信号忽略 |
| ⑤ 账户余额/持仓/总盈亏在 CLI 模拟盘区实时可见 |

## 6. M2 关键设计决策（架构师输入）

| # | 决策 | 说明 |
|---|---|---|
| D1 | 统一 1min K 线驱动规则链 | A股/美港股 ~3s 轮询快照按自然分钟聚合成 `Candle`，分钟收盘 `is_closed=True`；指标与规则链路跨市场零分支 |
| D2 | 多适配器并行编排 | 每适配器一个消费协程（监督重启粒度 = 适配器级），共享 State / Indicator / Rule / PaperEngine / AlertManager 链 |
| D3 | 统一代码规范 | 加密 `BTCUSDT`；A股 `600519.SH` / `000001.SZ`；港股 `0700.HK`；美股 `AAPL.US`；市场由后缀派生 |
| D4 | 延迟数据语义 | 触发时间戳 = 数据时间戳；告警附延迟前缀；冷却去重语义与 M1 一致（默认 300s） |
| D5 | 退避重试与主备切换 | 轮询适配器指数退避 1s→30s 封顶；A股东财主源连续失败 3 次切新浪，成功 1 次切回（阈值可配） |
| D6 | 诚实的成交模拟 | 市价单成交价 = 最新价 ± 滑点（bps 可配，不利于成交方）；费率按市场费率表精确计算；成交价/费用/金额必须单测对照手算 |
| D7 | 数据源白名单 | 币安仅 `.vision`；A股 = push2.eastmoney.com + hq.sinajs.cn；美港股 = qt.gtimg.cn；**tdx-connector 禁用**；akshare 仅评估、不入运行时依赖 |
| D8 | 信号方向语义 | 规则声明 `long` / `close` 方向（默认映射见 5.4）；仅多头模拟，不做空；M2 不实现止损止盈 |

## 8. M2 数据模型与存储扩展（架构师落地细节）

新增 dataclass（`quant/models.py` 或新模块）：`SignalRecord` / `Order` / `Fill` / `PositionEvent` / `Account`。

## 10. 测试与工程约束
